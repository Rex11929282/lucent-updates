# 璃音 Lucent：封面配色粒子回凝設計

## 目標

歌曲結束的粒子破碎過場，在下一首歌曲的封面、頭像與歌詞就緒後開始回凝。回凝粒子要使用下一首封面抽出的主色、輔色與高光色，而不是固定主題色。

## 範圍

- 僅變更 `shatter-in` 回凝期的粒子顏色。
- 散開與停留期繼續保留原本舊歌曲畫面的顆粒色彩。
- 不變更字幕鏡像、逐字填色、播放時鐘、海浪、唱片、普通裝飾粒子或視窗定位。

## 資料流程

1. 主行程標記下一首歌曲的封面已就緒，維持既有 `next-ready` 閘門。
2. 回凝前，Renderer 以已載入的下一首封面建立小型離螢幕 Canvas。
3. 取樣封面像素，濾除低飽和、近黑與近白像素，依出現比例挑出三個色群：主色、輔色、高光。
4. `SongTransitionLayer` 在 `shatter-in` 啟動時取得這組固定 palette；每顆粒子依既有穩定 seed 與索引選色。
5. 每顆粒子保有自己的回凝延遲，在回凝時間內從舊的畫面顆粒顏色平滑混合至新 palette 色，再依既有規則逐顆淡出。

## 回退與穩定性

- 封面空白、載入失敗、跨域畫布無法讀取或抽色不足時，使用現有主題色組作為固定 fallback palette。
- Palette 在一個回凝週期內不可重新抽樣，避免封面延遲或 React 重繪造成粒子跳色。
- 抽色使用一次性小畫布，不在動畫每幀重新讀取像素。
- 既有有限粒子數、單一 Canvas 與回收機制維持不變。

## 驗收

- 三種色彩差異明顯的封面各自產出不同粒子回凝 palette。
- 回凝期間粒子由舊畫面色平滑過渡到下一首封面色，不閃白、不隨機跳色。
- 無封面與無法抽色時，仍可完整回凝並使用主題 fallback。
- 快速切歌時，過期歌曲的 palette 不得套到最新歌曲。
- 原有粒子過場、字幕同步與 356 項既有測試不回歸。
