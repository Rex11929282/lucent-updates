# 璃音 Lucent：暫停呼吸與安全封包瘦身

## 目標

暫停播放時，桌面藥丸在原位平滑地淡化再恢復；播放恢復時立即停止。縮小 NSIS 安裝檔，但不移除任何使用者可見功能、網易雲連線、更新、唱片素材或 Electron 執行核心。

## 暫停呼吸

- 沿用既有 `fxPauseBreath` 設定，不新增重複開關。
- 將動畫放在藥丸的獨立內容合成層，而非直接改寫 LiquidGlass 本體。
- 週期固定為 3.2 秒，使用 ease-in-out；最低透明度與亮度為柔和可讀範圍。
- 僅在 `!playing && !effectsPaused` 時啟用。切歌粒子過場、控制台收起與播放恢復不得殘留暫停動畫。
- 不修改尺寸、定位、transform 或建立 JavaScript 計時器；因此不應觸發 ResizeObserver、視窗重設或滑鼠彈性抖動。

## 封包瘦身

- 維持 `compression: normal`，避免安裝解壓速度因最高壓縮而退化。
- 從應用封包排除 runtime 不需要的 source map、Markdown／說明文件與測試檔。
- 不排除 `dist/frames`、網易雲 API 執行模組、更新依賴、Electron 執行檔或任何目前使用的素材。
- 以新舊 NSIS 安裝檔大小、建置、完整測試和可啟動性驗證結果為準；不預先承諾縮減幅度。

## 驗證

1. 先寫測試，確認暫停可啟用、恢復／過場可停用，且不重用 transform。
2. 完整測試、Vite build、NSIS build 均須通過。
3. 檢查 app.asar 不再含被排除的檔案類型，並比較實際安裝檔大小。
4. 用實際 Electron 啟動驗證藥丸可顯示，暫停與恢復均不造成視窗重建。

## 不在範圍

- 不更換 Electron／Vite／React 框架。
- 不調整歌詞同步邏輯、房間同步、外觀素材或自動更新行為。
- 不新增遊戲功能或假音訊分析。
