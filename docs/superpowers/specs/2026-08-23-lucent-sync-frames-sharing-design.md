# 璃音 Lucent：同步、外框、原地過場與參數分享設計

日期：2026-08-23

## 目標與執行順序

第一階段先完整修復網易雲換句晚一拍，完成自動測試、真實播放驗證並產出階段性 EXE。第二階段在現有 Electron、React、液態玻璃、歌詞鏡像、房間與設定架構上擴充外觀和局域網功能，最後再做完整回歸與最終 EXE。

不新增遊戲 HUD、遊戲偵測、遊戲 Profile、FPS／MOBA 功能，也不更換技術框架。

## 一、換句同步

目前網易雲 DOM 已提供 `.line.current`，但程式仍以文字色彩 alpha 最大值挑選高亮行。換句過場期間舊行與新行可能同時為 alpha 1；目前的 `a > bestA` 會保留 DOM 中較早的舊行，造成晚一行或晚一拍。

新選線順序：

1. 明確的 `.line.current`。
2. `aria-current=true` 或等價 current 資料屬性。
3. 以播放進度與 `.line[data-time]` 選擇最接近的合法行。
4. 只有前三者都不可用時，才使用 alpha 高亮降級。

網易雲頁面注入一個可重用的讀取器與 MutationObserver。DOM class、style、文字或歌詞列表替換時更新 `window.__lglLyricSnapshot` 與遞增序號；CDP 輪詢只讀最新快照並定期自我修復 observer。輪詢頻率由 150ms 降為 80ms，但不建立多個 timer。主行程依歌曲 ID、行索引、文字及序號去重；Renderer 仍以 mirror 決定顯示句，YRC 決定逐字進度。

驗收包括：換句、相同歌詞重複句、雙語、暫停、拖動、切歌、DOM 重新掛載、current class 與 alpha 同時存在。真實量測記錄網易雲 current 行變更與 Overlay 文字變更的時間差；目標正常值不超過一個 80ms 輪詢週期，不得停留上一句。

## 二、噪點防閃爍

移除位於模糊 filter 內的高頻 `repeating-conic-gradient`。噪點改為固定紋理圖層：

- 位於共同 `visualclip` 內，受同一圓角裁切。
- 不依滑鼠位置重新生成。
- 不放入每幀改變的 filter 或 transform。
- 只透過 opacity 調整強度。
- 固定 compositor layer，滑鼠液態變形時不重新光柵化紋理。

噪點開啟後，滑鼠移入、移動、移出及液態回彈都不得出現明暗閃爍、材質跳位或視窗尺寸抖動。

## 三、文字間距與歌名位置

新增：

- `lyricTranslationGap`：原文與翻譯上下間距，0–32px。
- `translationProgressGap`：翻譯與進度條間距，0–24px。
- `songNamePos = bc`：歌名中下。

中下歌名使用既有內容流，不做 absolute 疊放，因此不遮擋進度條、字幕或唱片。尺寸變更仍由 ResizeObserver 量測，並觸發螢幕邊界重新驗證。

## 四、外框素材

六張透明 PNG 依比例分成兩類：

- 藥丸外框：`39fc...png`、`bb1b...png`、`dba0...png`，原始比例 3:1。
- 唱片外框：`1a83...png`、`1f8f...png`、`eb9f...png`，原始比例 1:1。

素材複製到 `public/frames/pill/` 與 `public/frames/vinyl/`，使用穩定名稱和 manifest，不讀取 Downloads 絕對路徑。

### 藥丸外框

藥丸框使用每張素材的 9-slice metadata。四角及端部裝飾不縮放變形，只延展中段；整個 frame layer 固定在藥丸可見 bounds 內，受 `--radius` 裁切。每張外框宣告內容安全內距，啟用後自動增加 padding，避免覆蓋字幕、歌名、唱片和進度條。

### 唱片外框

唱片框使用方形 `<img>` 等比例 contain，與唱片同中心、同 ResizeObserver 尺寸基準。外框位於唱片裝飾層，不參與旋轉唱片內容，不遮住歌詞。缺圖或載入失敗時隱藏外框並保留普通唱片。

設定提供「無」和對應素材名稱。所有素材切換立即預覽並保存。

## 五、原地換歌過場

藥丸不移動 BrowserWindow，也不移到螢幕中央。換歌時僅在原位置播放：

1. `collapse`：舊內容向藥丸自身中心平滑壓縮。
2. `hold`：清除舊歌詞，顯示 `♪`，等待新歌曲資料。
3. 可選 `shatter`：只在藥丸裁切區內顯示有限數量、可回收的玻璃碎片。
4. `expand`：新歌名與新歌詞從自身中心展開回正常尺寸。

過場 transform 放在獨立 composition wrapper，不覆蓋液態玻璃、3D tilt、換句 scale 或唱片 transform。新歌曲 revision 驅動狀態機，舊 revision 的 timeout 不得提交。房主把 transition revision／phase／時間傳給成員；每台電腦在原位播放同一階段。

## 六、新玻璃流光

先前刪除的整條直線流光不恢復。新增獨立、受 `visualclip` 裁切的流光層：

- 模式：無、柔光橢圓、水滴、弧形。
- 形狀寬度、高度。
- 移動時間。
- 出現間隔。
- 亮度、模糊、透明度。
- 方向：左至右、右至左、斜向。

每個週期只在短時間內顯示，其餘時間完全透明；不建立全螢幕 Canvas，不改變 Overlay bounds，也不使用隨機音訊假節拍。

## 七、局域網雙向參數提案

移除目前成員收到房主 `state.style` 後自動覆蓋並保存的行為。播放、歌詞和進度仍自動同步；外觀只透過明確提案傳送。

### 傳送方向

- 房主可傳給全部成員或指定成員。
- 成員只能傳給房主。
- 不允許成員直接傳給其他成員。

### 提案內容

`style-offer` 含 request ID、發送者 ID／名稱／角色、建立時間、建議配置名稱、`glass` 與已清理的視覺 `cfg` 快照。排除視窗位置、置頂、滑鼠穿透、鎖定、安全邊距、吸附、房間密碼、播放位置及本機同步偏移。

接收端未操作前不修改本機設定。控制台顯示來源與主要差異摘要，提供：

- 「接受並保存」：立即套用已驗證的外觀快照，建立命名配置 `來自 <發送者>－<日期時間>`，再持久化。
- 「拒絕」：不修改設定，回覆發送者。

每個 offer ID 只能處理一次。斷線、過期或重送不得重複套用。接收結果回傳發送者並在房間頁顯示。待處理提案保存在主行程記憶體；已接受的配置保存於既有 `profiles[]`。

## 八、設定與相容性

Config Schema 升級，新增文字間距、外框選擇、流光、換歌過場設定。舊設定透過 default merge 載入；舊 `fxSheen` 仍忽略，不復活。外觀 Profile 和局域網提案包含新增視覺欄位，個人視窗行為仍排除。

## 九、性能與回歸

- 噪點、外框與流光不得建立每幀 React state。
- 換歌碎片有限量並於動畫結束回收。
- 控制台關閉時不運行預覽動畫。
- 不破壞歌曲辨識、鏡像句、YRC 卡拉 OK、暫停、跳轉、唱片、進度條、螢幕邊界、局域網播放同步和單一實例。
- 第一階段同步修復通過後產出階段性 `Lucent 1.0.0.exe`；全部功能完成後再產出最終 EXE。
