# 璃音 Lucent 裝飾粒子設計

## 目標與範圍

在現有歌詞藥丸中加入三種可選裝飾特效：流星雨、櫻花飄落與雪花飄落，另保留「無」。不加入玻璃流光、星塵、極光、霓虹脈衝、粒子飄帶、電流掃描、呼吸光霧或 RGB 掃描線。

特效只能裝飾藥丸，不得改變歌曲辨識、歌詞鏡像、逐字高亮、進度條、拖曳、滑鼠穿透或局域網同步行為。本階段不封裝 EXE。

## 渲染架構

新增一個只負責裝飾粒子的 Canvas 元件。Canvas 位於背景材質之上、文字與進度條之下，尺寸由藥丸視覺裁切層的實際內容尺寸決定，不建立全螢幕 Canvas。

Canvas 與封面背景、背景材質共用同一個圓角裁切容器。裁切以現有 `--radius` 為唯一來源，因此所有圓角預設與自訂圓角都得到一致結果。Canvas 不參與版面計算，不增加 Overlay bounds，也不攔截滑鼠事件。

粒子引擎使用單一 `requestAnimationFrame` 更新迴圈和固定上限的物件池。粒子離開邊界後回收到池中，模式切換時重用或清空池，不為每個粒子建立 DOM、Timer 或 Interval。

## 特效模式

### 流星雨

流星由亮核心與漸弱尾跡組成，支援多粒子同時移動。基本參數為數量、生成頻率、速度、長度、粗細、透明度、方向與顏色；進階參數為隨機速度、尾跡長度、尾跡透明度、發光強度、發光範圍、核心亮度與邊緣柔化。

方向支援左上至右下、右上至左下、左至右、右至左及隨機。顏色支援固定色、雙色、漸層、隨機色、RGB 與跟隨主題。歌詞換句時可選擇短暫增加亮度與生成量，事件只來自現有換句訊號。

### 櫻花飄落

花瓣使用 Canvas path 繪製，不依賴外部圖片。每片花瓣具有落速、左右擺動、旋轉、尺寸、透明度與景深差異。基本參數為數量、速度、尺寸、顏色與強度；進階參數為擺動幅度、旋轉速度、景深差異、風向和透明度。

### 雪花飄落

雪景混合小型柔化雪點與低比例六角雪晶。基本參數為數量、速度、尺寸、亮度與強度；進階參數為風向、飄移幅度、柔化、雪晶比例和透明度。雪花不使用隨機跳動模擬音訊。

## 動畫與效能

粒子的隨機值只用於自然生成位置、尺寸、角度、速度細微差異和顏色變化，不代表音量、節拍或 FFT。播放狀態可控制更新節奏，但不偽造音訊分析。

Overlay 顯示且特效啟用時以 `requestAnimationFrame` 更新；程式暫停播放時降低生成與更新頻率；特效為「無」、頁面不可見或元件卸載時取消動畫。控制台預覽只有在預覽可見且啟用播放預覽時才運行。

每種模式設置保守的粒子數硬上限，設定值在讀取和寫入時 Clamp。Canvas 依裝置像素比例繪製，但限制最大像素倍率，避免高 DPI 下 GPU 負擔失控。

## 設定 UI

沿用現有可收合「裝飾特效」分類。首層只顯示模式、數量、速度、強度及主要顏色；「進階」展開後才顯示模式專屬參數。切換模式後不顯示無關 Slider。

新增「重設此區」，只重設裝飾特效設定。調整參數立即反映到控制台預覽和 Overlay，不需要按套用。

## 設定保存與相容性

新增 `decorationMode` 與三種模式各自的參數群組。設定納入目前 Config、外觀命名配置及局域網主持人視覺同步。啟動時以 default merge 補齊舊 Config；未知模式降級為「無」，不要求刪除舊設定檔。

舊版已淘汰的進度條效果不會因本次工作恢復。裝飾設定不覆蓋同步偏移、置頂、穿透、鎖定或視窗位置。

## 驗證

- 三種模式在視覺上具有結構性差異，不只是改色或改速。
- 流星具有多粒子、核心和尾跡；櫻花具有花瓣、擺動與旋轉；雪花同時具有雪點與雪晶。
- 所有粒子在五種圓角、自訂圓角、唱片顯示或隱藏、短句、長句、雙語與最大字級下都不超出藥丸。
- Canvas 不擴大 Overlay bounds，不攔截滑鼠，不遮住文字、歌名、唱片或進度條。
- 切換模式、暫停、恢復、換歌及卸載時不殘留動畫迴圈或粒子。
- 設定與命名配置在重啟後可恢復，舊 Config 可正常載入。
- 自動測試、Vite build、Overlay 與控制台實際檢查通過；回歸歌曲辨識、鏡像同步、逐字歌詞、進度條、拖曳邊界、滑鼠穿透與局域網共享。

## 明確不做

不加入其他裝飾特效，不加入假音訊分析，不增加全螢幕 Canvas，不增加遊戲 HUD、遊戲偵測、遊戲模式、遊戲 Profile 或任何遊戲專用系統，也不在本階段封裝 EXE。
