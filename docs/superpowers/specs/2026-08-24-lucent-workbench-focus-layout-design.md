# 璃音 Lucent 工作檯專注式設定設計

## 已確認決策

採用 A：開啟控制台時，桌面藥丸以短暫縮小淡出收起；控制台關閉時，藥丸在原位淡入恢復。收起只影響 Overlay 視窗可見性，不停止播放、歌詞鏡像、房間時鐘或任何歌曲資料載入。

## 目標

把冷白液態工作檯整理成清楚、可宣傳、可操作的專注式設定介面：中央預覽必須和桌面藥丸共用同一套視覺渲染；點擊模組後，選中模組移到左側、預覽保留中間、對應設定在右側展開；整個視窗可以從標題列拖曳。

## 結構與互動

### Overlay 收起與恢復

1. 主行程要求 Overlay 收起時先向 Renderer 發送可見性狀態。
2. Renderer 為藥丸外層套用 160ms 的 `transform` 與 `opacity` 收起動畫。
3. 動畫結束後主行程呼叫 `overlay.hide()`；這不卸載 Renderer，因此同步狀態持續更新。
4. 控制台關閉時主行程先 `showInactive()` Overlay，再通知 Renderer 移除收起狀態，讓藥丸從原本位置回彈顯示。
5. 快速開關控制台時取消前一個延遲，避免 Overlay 在控制台已關閉後被錯誤隱藏。

### 同源藥丸預覽

`ConsoleCapsulePreview` 不再使用獨立的 `LiquidGlass` 與簡化排版。它會以 `Capsule` 的 preview mode 直接呈現同一個視覺樹，並傳入目前 `glass`、`cfg`、歌曲、歌詞、翻譯、封面、唱片、進度和高亮 refs。

preview mode 不得：寫入 Overlay 尺寸、呼叫 Overlay 拖曳位置 IPC、捕捉畫面、觸發換歌過場回報、攔截桌面滑鼠。它只讀取設定並即時繪製；因此所有外觀設定一律在桌面與控制台預覽同步出現。

### 版面

初始狀態維持四張漂浮卡片圍繞中央預覽。展開後固定為三欄：

```text
[選中卡片]    [同源預覽藥丸]    [設定內容]
```

- 選中卡片：吸附至左欄並保有立體 hover／按壓回饋。
- 預覽：保持中央，不被設定面板覆蓋，也不使用另一套假外觀。
- 設定面板：從右側展開，保留既有收合分類與所有功能。
- 非選中卡片：淡出、縮小且不能誤點；收合後回到保存的位置。

動畫限於 `transform`、`opacity` 和已存在的一層高光，不為每張卡片建立 timer、Canvas 或連續 blur。

### 可讀性

- 工作檯、卡片、設定面板、區塊標題、輸入框、下拉選單與按鈕均使用可見的青灰外框。
- 主要文字採深藍灰高對比色；輔助文字仍可辨識，不能只依賴桌面背景或半透明白色。
- 檢閱面板與卡片以不透明度足夠的冷白材質提供穩定對比；桌面仍可略微透見。
- 保留 `prefers-reduced-motion`：移除位移動畫而不影響可讀性和操作。

### 視窗拖曳

控制台標題列設為 Electron `-webkit-app-region: drag`。關閉按鈕、卡片、表單欄位、滑桿與面板內互動元素設為 `no-drag`，所以拖曳視窗不會搶走正常的點擊操作。

## 範圍與限制

- 不更換 Electron、React、Vite 或液態玻璃元件。
- 不修改歌詞鏡像、CDP、房間同步、播放仲裁、桌面藥丸定位或任何更新服務。
- 不新增遊戲功能、播放器功能、設定欄位或依賴套件。
- 不使用桌面擷取或假音訊分析。
- 全部新增互動以現有繁體中文 UI 呈現。

## 驗收

1. 控制台開啟時，桌面藥丸收起但歌曲與歌詞狀態不重置；關閉後原位恢復。
2. 預覽包含和桌面同樣的 `Capsule` 視覺內容，外觀調整立刻同步。
3. 展開卡片時，左為選中卡片、中為預覽、右為設定；過場流暢且無重疊。
4. 所有設定區與文字在桌面背景較亮或較雜時仍清楚。
5. 可從空白標題列拖曳視窗，所有按鈕／表單仍可點擊和輸入。
6. 回歸現有播放、房間、外觀與更新控制台測試；不封裝 EXE。
