# 璃音 Lucent 控制台大眾化重設計

## 目標

將目前的液態工作檯改為容易理解、操作快速的正式桌面控制台。新使用者第一次啟動即可知道璃音的用途與下一步；既有播放、外觀、房間、更新、隱私與桌面藥丸功能全部保留。

成功標準：控制台啟動即顯示、主要功能三次點擊內可到達、常用設定不需要展開進階區、控制台不透出桌面、切頁與調整設定保持順暢，而且不影響歌詞同步及藥丸動畫。

## 視窗與啟動流程

- 每次執行璃音預設開啟控制台；控制台開啟期間桌面藥丸收起，避免同時出現兩份預覽。
- 第二次執行程式、點擊系統匣圖示及 `Ctrl+Alt+S` 都開啟並聚焦控制台。
- 藥丸右鍵選單移除「打開控制台」，保留「鎖定位置」。
- 控制台改為一般視窗，不再永遠置頂；桌面藥丸仍遵循自己的置頂設定。
- 控制台可調整大小，預設 1080×720，最小 860×600；窄視窗將右側面板改為覆蓋式抽屜，不壓縮主要內容到不可操作。
- 右上角關閉首次提供「顯示桌面藥丸／縮到系統匣／徹底退出」，可記住選擇；軟體設定可恢復為每次詢問。
- 控制台可設定啟動時顯示控制台或藥丸，預設為控制台。

## 控制台資訊架構

- 使用固定三區版型：左側導覽、中央主要工作區、右側情境設定。
- 左側固定六項：首頁、播放、外觀、房間、軟體設定、幫助。圖示與文字同時顯示，不要求使用者猜圖示。
- 取消可拖曳模組、浮動卡片與模組座標保存。舊版 `ui.workbench` 可讀但不再渲染；舊分頁狀態遷移到相近的新頁面。
- 每頁只突出一個主要任務；常用功能直接顯示，低頻參數放入「進階設定」，最多一層收合。
- 控制元件統一使用清楚標籤、固定行高、可見邊框與一致的開關、選單、滑桿及主要／次要按鈕樣式。

### 首頁

- 顯示目前歌曲、音樂來源、歌詞同步、房間與更新狀態，以及使用正式 `Capsule` 元件的即時藥丸預覽。
- 狀態異常時顯示具體原因與真實可用的修復按鈕，不只顯示錯誤文字。
- 提供顯示桌面藥丸、測試預覽動畫、重新連接精準同步及重新開啟教學四個快捷操作。
- 第一次使用保留三步完成清單：連接音樂、成功顯示歌詞、選擇外觀並顯示藥丸。清單由真實狀態自動完成。

### 播放

- 中央只處理搜尋、網易雲歌單、璃音本機歌單與播放佇列，使用一層分頁切換。
- 右側固定顯示目前歌曲、播放控制、音量、來源優先級與精準同步健康狀態。
- 網易雲登入留在播放頁；資料與隱私移到軟體設定。
- 房間聽眾沿用現有權限規則；沒有播放權限時主要動作顯示為「點歌」而非「播放」。

### 外觀

- 中央固定顯示與桌面完全相同的藥丸預覽及快速預設；切換右側分類時預覽不卸載。
- 右側分類為：快速預設、藥丸與唱片、歌詞文字、背景材質、進度條、動畫與特效、視窗行為。
- 每次只顯示一個分類；依目前模式動態顯示真正有效的參數，進階參數預設收合。
- 保留命名配置的保存、套用、覆寫及刪除；設定搜尋可跳到對應分類與控制項。

### 房間

- 未加入房間時，中央只顯示「建立房間」與「加入房間」兩條清楚流程。
- 已加入房間後，中央以一層分頁切換播放佇列與成員列表。
- 右側顯示房間資訊、複製邀請、權限、外觀分享及離開房間；只有房主或獲授權成員看到相應操作。
- 錯誤、重連與延遲品質放在頁首狀態列，不混入操作表單。

### 軟體設定與幫助

- 軟體設定分類：一般、控制台主題、更新、快捷鍵、資料與隱私、關於與幫助。
- 一般設定包含啟動畫面、關閉行為及隨 Windows 開機啟動；開機啟動預設關閉。
- 控制台主題提供跟隨系統、固定亮色、固定深色；預設跟隨 Windows，控制台內容區永遠不透明。
- 更新沿用現有自動更新及穩定／測試頻道；隱私沿用移除登入、清除本機歌單及重設璃音設定。
- 設定搜尋只索引現有控制項，結果跳到實際設定，不建立無功能入口。
- 幫助頁包含用途說明、三種音樂來源、精準同步方式、房間使用方式、快捷鍵及重新播放教學。

## 首次使用教學

- 僅全新安裝第一次啟動自動顯示；舊設定遷移時標記為已完成，避免更新後突然彈出。
- 第一頁介紹桌面即時歌詞、液態藥丸與一起聽房間；第二頁說明電腦網易雲、軟體內播放及房主同步三種來源。
- 教學可跳過且不強迫登入；完成或跳過都保存版本。幫助頁可隨時重新開啟。
- 教學結束後回到首頁三步清單，不自動播放、登入或修改使用者外觀。

## 視覺、互動與效能

- 控制台視覺採完全不透明的 Windows 亮／暗底色，重點色跟隨 Windows 強調色；桌面藥丸外觀不受控制台主題影響。
- 為保留圓角，視窗最外圍僅允許圓角外的像素透明；可見控制台區域不得看到桌面，也不使用 `backdrop-filter`。
- 導覽切換 160–220ms 淡入位移，右側面板 180–240ms 滑入，按鈕僅做 1–2px 位移或 0.98 倍按壓回饋。動畫可中斷，不排隊重播。
- 使用 CSS transition 與 transform／opacity；不新增 `setInterval`、粒子、桌面擷取或大面積 blur。
- 切頁不重新建立共享播放監聽或正式藥丸預覽；播放時鐘與歌詞更新保持現有單一資料來源。
- 遵循 `prefers-reduced-motion`，減少動態時停用非必要位移但保留狀態切換。
- 控制台隱藏後停止教學及預覽動畫，不影響桌面藥丸和播放服務。

## 設定與相容性

- Config Schema 升級一版，新增應用設定：`theme`、`startupView`、`closeBehavior`、`launchAtLogin`，以及 UI 狀態：`selectedPage`、`onboardingVersion`、外觀右側分類。
- `theme` 預設 `system`、`startupView` 預設 `console`、`closeBehavior` 預設 `ask`、`launchAtLogin` 預設 `false`。
- 舊版 `ui.workbench.activeModule` 映射至播放／外觀／房間／軟體設定；模組座標與透明材質選項安全忽略，不要求刪除舊設定檔。
- 關閉選擇、教學完成狀態、主題、啟動方式與右側分類均持久化；外觀、播放、同步、房間與藥丸位置設定不被覆寫。
