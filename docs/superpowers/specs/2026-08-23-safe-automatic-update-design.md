# 璃音 Lucent 安全自動更新設計

## 目標

已簽署的 Windows NSIS 安裝版在發現新版本後自動背景下載；只有在未播放音樂且未主持房間時才自動重新啟動並安裝。更新不得中斷播放、房間主持或使用者設定。

## 範圍

- 只作用於已封裝、非 Portable、且帶有 `app-update.yml` 的安裝版。
- 開發版維持停用；Portable 維持手動下載。
- 使用既有 HTTPS 更新來源與 `electron-updater`。
- 不改變音樂 Provider、歌詞、房間、播放或授權邊界。

## 行為

1. 程式啟動 30 秒後檢查更新，之後每四小時檢查一次。
2. 發現更新後自動背景下載，控制台仍顯示版本與進度。
3. 下載完成後：
   - 若沒有播放音樂且不是房主，立即呼叫安全重啟安裝。
   - 若正在播放或主持房間，保留「更新已準備好」狀態；當狀態第一次變為安全時自動安裝。
4. 使用者仍可在更新頁按「立即安裝」，但在不安全狀態不會強制中斷。
5. 下載、安裝或網路錯誤只顯示去除路徑後的公開錯誤訊息。

## 實作界線

- `updateService` 負責檢查、下載、等待安全狀態與單次安裝。
- 主程序提供目前是否播放／主持房間的安全判定；播放或房間狀態改變時重新評估待安裝更新。
- Renderer 只讀取更新狀態，不直接呼叫 Electron 更新器。
- 不新增外部服務、不部署更新站、不封裝安裝檔。

## 驗收

- 自動模式設為 `autoDownload=true`、`autoInstallOnAppQuit=true`。
- 更新可用時自動下載；下載完成且安全時只安裝一次。
- 不安全時延後，直到狀態轉安全才安裝。
- 開發版與 Portable 行為不變。
- 全量測試與 Vite 建置通過。
