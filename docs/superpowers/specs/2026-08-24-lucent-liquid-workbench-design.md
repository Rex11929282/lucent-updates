# 璃音 Lucent 冷白玻璃液態工作檯設計

## 目的

把現有的控制台從固定分頁與長設定表單，改成可拍入宣傳片的冷白半透明「液態工作檯」。這是非商用開發版的 UI 重設計，不新增付款、授權、遊戲或音訊分析功能，也不改變歌詞鏡像、播放仲裁、房間同步與更新服務的實際行為。

## 已確認的視覺方向

- 風格：冷白玻璃、可看見桌面、整個視窗四角大圓弧、iOS 風格的近似材質與回彈。
- 核心物件：中央大型歌詞藥丸預覽。
- 互動：播放、外觀、房間、歌單與配置以漂浮玻璃模組存在，靠近時小幅磁吸／亮起，點選時才展開參數。
- 不使用：固定左側欄、傳統分頁列、常駐長卡片牆、桌面擷取式背景模糊。

## 結構

### 1. 視窗殼層

`consoleWin` 保持 frameless + transparent。Renderer 的根節點負責可見圓角、裁切與冷白材質；視窗外部維持透明，讓桌面從四個圓角外露出。

Windows/Electron 透明視窗不能可靠地對桌面像素做真實 backdrop blur。材質將使用可見桌面的低透明度染色、內側高光、細緻噪點與漸層折射來近似玻璃，不能重新加入桌面擷取或每幀模糊。

### 2. 工作檯核心

中央為 `Capsule` 的獨立預覽，不複製歌詞渲染邏輯。它使用現有 `state.glass`、`state.cfg`、歌曲封面與歌詞資料，所以材質、歌詞清晰度、唱片、進度條、裝飾粒子與雙語狀態都會即時反映。

核心預覽周圍最多同時出現四個模組：

- 播放模組：目前歌名、播放／暫停、進度與搜尋入口。
- 材質模組：背景材質、透明度、清晰度與快速外觀入口。
- 房間模組：房主／成員、延遲、加入／離開與同步摘要。
- 配置模組：外觀縮圖、名稱、套用、另存、覆蓋與刪除。

更新設定和較少使用的進階玻璃參數不會消失；它們放進由對應模組打開的「玻璃檢閱面板」，避免干擾日常工作檯。

### 3. 互動層級

1. 靜止：模組是低對比、安靜的半透明物件。
2. 接近：指標進入模組附近有限範圍時，僅以 `transform`、`opacity` 和一層高光做小幅浮起／磁吸。
3. 聚焦：點擊模組後，其他模組退後，選定模組展成參數面板；修改立即更新中央預覽。
4. 收合：點擊空白處、Esc 或再次點擊聚焦模組後回到工作檯。

拖曳只適用於工作檯內的模組排列；不改變桌面歌詞藥丸的螢幕位置。模組位置可保存為個人 UI 偏好，但不作為房間外觀共享資料。

### 4. 視覺規則

- 視窗圓角：外殼 28px，內部模組 16px，歌詞預覽維持藥丸圓角。
- 冷白材質：白色／青灰色低飽和染色，不加入紫粉極光主色。
- 可讀性：歌詞與操作文字皆有固定高對比色，桌面透見不影響字幕清晰度。
- 層次：背景材質 < 模組 < 核心藥丸 < 展開面板 < 選單／確認框。
- 宣傳片：進場先顯示桌面與圓角玻璃，再由中央藥丸帶出模組；不把大量滑桿同時放進畫面。

### 5. 性能與無障礙邊界

- 不使用桌面擷取、全視窗 Canvas、每一模組各自的 timer，或無限 CSS blur 動畫。
- 指標回應統一由一個 `requestAnimationFrame` 節流；停用動態效果或最小化時不更新。
- 對 `prefers-reduced-motion`：停用磁吸、回彈與展開位移，保留立即可用的控制。
- 保留鍵盤焦點、Esc 收合、可見按鈕文字和現有繁體中文功能說明。

## 影響範圍

主要改動預計限定在：

- `src/ConsoleWindow.jsx`：用工作檯結構取代目前頂部 tabs，但沿用既有房間、播放、外觀與更新子功能。
- `src/styles.css`：新增 Console 專用殼層、圓角裁切、冷白材質及受限的互動動畫。
- `shared/defaults.json`、`shared/stateMigration.cjs`：只在需要保存模組位置／工作檯 UI 狀態時新增向後相容欄位。
- `electron/main.cjs`：只在需要微調控制台視窗尺寸、最小尺寸或透明視窗行為時變更；不動 Overlay 視窗、同步或播放器程式。

不改動：歌詞時間線、CDP 鏡像、卡拉 OK、封面載入、房間時鐘、更新 feed、藥丸邊界系統、內部播放器仲裁。

## 驗收

1. 控制台整體與四角都是圓弧，桌面在圓角外及半透明工作檯中可見。
2. 不再以固定 tabs／左側欄作為主操作方式，現有功能仍可到達。
3. 中央預覽即時呈現外觀修改，且不複製或干擾實際歌詞同步。
4. 模組磁吸、展開、收合不造成持續 CPU／GPU 增長或畫面閃爍。
5. 播放、房間、外觀配置與更新功能回歸測試通過。
6. 所有新增 UI 狀態重開後可恢復，舊設定可正常載入。
